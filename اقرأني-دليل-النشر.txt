دليل تحديث ونشر تطبيق ToMobilti
=====================================================

هذه النسخة الجديدة تحتوي على:
  - اسم التطبيق الجديد: ToMobilti
  - منبه صوتي قبل انتهاء الوثائق بيومين
  - منبه صوتي قبل صيانة تبقى لها 500 كم
  - صور كرتونية (زيت، محرك، عجلات، وثيقة)
  - أزرار تحديث سريع للمسافة: +1 +10 +100 +1000
  - تبسيط تسجيل الوقود: التاريخ + المبلغ فقط

لتحديث التطبيق عند الزبناء (إذا كان منشوراً مسبقاً):
  1) ارفع الملفات الخمسة الجديدة إلى نفس المستودع في GitHub
     (Add file ← Upload files ← اختر الملفات ← Commit changes)
  2) هذا كل شيء! خلال دقائق سيتلقى كل زبون التحديث تلقائياً
     عند فتح التطبيق (بفضل ملف sw.js الجديد)

ملاحظة عن المنبه الصوتي:
  المتصفحات تمنع الصوت قبل أول لمسة من المستخدم،
  لذا سيعمل المنبه بعد أول تفاعل (ضغطة) داخل التطبيق.

ملفات الحزمة:
  - index.html  (لا تغيّر اسمه)
  - manifest.webmanifest
  - sw.js
  - icon-192.png / icon-512.png
